# Batch ASR Processor for LNG GraphRAG

This system processes YouTube videos one at a time: downloads each video, transcribes it using ASR, saves the transcription, and then deletes the video file before moving to the next one.

## Features

- **One-at-a-time processing**: Downloads, processes, and cleans up each video individually
- **Memory efficient**: Only keeps one video in memory at a time
- **Progress tracking**: Updates CSV file with processing status
- **Error handling**: Continues processing even if individual videos fail
- **Automatic cleanup**: Deletes video files after transcription
- **Concurrent transcription**: Processes audio chunks in parallel for faster ASR

## Files

- `batch_asr_processor.py` - Main batch processing script
- `run_batch_asr.py` - Simple interactive runner
- `VODs/videos.csv` - Video list with processing status
- `transcriptions/` - Output directory for transcriptions

## Usage

### Option 1: Interactive Mode (Recommended)
```bash
python run_batch_asr.py
```

This will:
1. Check for the CSV file
2. Ask for processing options
3. Start batch processing with your preferences

### Option 2: Direct Script Usage
```bash
# Process all pending videos
python batch_asr_processor.py

# Process first 5 videos
python batch_asr_processor.py --max 5

# Process from index 10, maximum 3 videos
python batch_asr_processor.py --start 10 --max 3

# Use custom CSV file
python batch_asr_processor.py --csv ./custom_videos.csv
```

## Processing Flow

For each video:

1. **Download** 📥
   - Downloads video from YouTube using `download_from_youtube.py`
   - Converts to WAV format at 16kHz sample rate
   - Saves to `./VODs/{title}.wav`

2. **Load & Split** 🎵
   - Loads audio file using torchaudio
   - Splits audio at silence points (1-5 minute chunks)
   - Prepares chunks for parallel processing

3. **Transcribe** 🎤
   - Processes audio chunks concurrently (max 3 at a time)
   - Uses Breeze-ASR-25 model for transcription
   - Handles errors gracefully

4. **Save** 💾
   - Combines all transcriptions
   - Saves to `./transcriptions/{title}.txt`
   - Updates CSV status to "completed"

5. **Cleanup** 🗑️
   - Deletes the downloaded WAV file
   - Frees up disk space
   - Moves to next video

## CSV Status Tracking

The system updates the CSV file with processing status:
- `pending` - Not yet processed
- `completed` - Successfully processed
- `failed` - Processing failed
- `skipped` - Already exists (from download script)

## Error Handling

- **Download failures**: Marks as "failed" and continues
- **Transcription errors**: Logs error and continues
- **File cleanup issues**: Shows warning but continues
- **Keyboard interrupt**: Gracefully stops and shows progress

## Requirements

- All dependencies from `requirements.txt`
- YouTube cookies file at `./VODs/www.youtube.com_cookies.txt`
- CSV file with video list (generated by download script)

## Output

Transcriptions are saved as text files in `./transcriptions/`:
```
transcriptions/
├── 【LNG】2025OCT 10月大家在幹嘛啊.txt
├── 【LNG】2025SEP 噁之呼吸一之型 紫色惡魔 我看到你了啦.txt
└── ...
```

Each file contains the full transcription of the video, with each audio chunk on a separate line.

## Performance

- **Memory usage**: Low (only one video at a time)
- **Disk usage**: Minimal (files deleted after processing)
- **Speed**: Depends on video length and ASR model performance
- **Concurrency**: 3 parallel audio chunks per video

## Troubleshooting

### Common Issues

1. **"CSV file not found"**
   - Run the download script first to generate `videos.csv`

2. **"Download failed"**
   - Check YouTube cookies file
   - Verify internet connection
   - Some videos may be region-locked

3. **"Model loading failed"**
   - Check internet connection for model download
   - Verify CUDA/CPU availability
   - Check disk space

4. **"Transcription failed"**
   - Check audio file quality
   - Verify model is loaded correctly
   - Some audio may be too quiet or corrupted

### Monitoring Progress

The script provides detailed progress information:
- Download status for each video
- Audio chunk processing progress
- Transcription completion status
- File cleanup confirmation
- Final statistics
